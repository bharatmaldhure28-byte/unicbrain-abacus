# UnicBrain Academy website

Static website for UnicBrain Academy (Abacus classes, ages 4-14).

## Files
- `index.html` - the whole website (HTML, CSS, JS and images in one file)
- `CNAME` - custom domain for GitHub Pages (change if your domain differs)
- `.nojekyll` - tells GitHub Pages to serve the file as-is

## Edit
- Play / Learn links: search `const PLAY=` and `const LEARN=` in `index.html`, and put each URL in the third field (the empty `''`).
- Contact details: search `9960039060`.
- Visit counter: uses the free CounterAPI service (namespace `unicbrain-academy-site`). Change the name in `const CNT=` if you want a private counter.
